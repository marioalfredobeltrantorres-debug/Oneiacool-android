1) Android Studio > File > Open > esta carpeta. Espera a que termine "Gradle sync" (si pide version de Gradle, acepta la recomendada).
2) Conecta tu celular con "Depuracion USB" y pulsa Run, o Build > Build APK(s) para sacar el .apk.
3) Acepta los permisos (micrófono, cámara, llamadas, contactos, ubicación).
Para actualizar la IA: reemplaza app/src/main/assets/oneiacool.html y vuelve a compilar.
